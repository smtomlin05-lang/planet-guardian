# Planet Guardian

An original Defender-style side-scrolling shooter for Android (landscape).

- **Left thumb:** drag anywhere on the left to fly. Push up/down to climb or dive, push left/right to turn and thrust.
- **Right thumb:** FIRE (hold for rapid fire), REV (turn round), BOMB (clears the screen), HYPER (warp somewhere random, small risk).
- Landers try to carry humanoids to the top of the screen, where they turn into mutants. Shoot the lander, catch the falling humanoid and fly it back down.
- Lose every humanoid and the planet is lost until wave 5, 10, 15...

GitHub Actions builds the APK on every push and puts it on the `apk` branch.
